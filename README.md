## 🌟 Key Architecture & Highlights

- **Interactive 3D WebGL Avatar**: Custom rigged 3D character with real-time mouse-tracking head rotation, HDR environment illumination, and physical material shaders.
- **GSAP Scrollytelling**: Frame-synchronized scrubbing with zero layout shift, seamless pinned sections, and dynamic horizontal scroll pagination.
- **Peer-Reviewed Research Showcase**: Highlights published AI/ML research in clinical informatics and biomedical language modeling (*ICDSINC 2025*).
- **GPU & Mobile Performance Optimized**: DPR-capped WebGL rendering (`max 1.75`), power-preference tuning, and async Draco mesh decompression for instant 60 FPS transitions.

## ⚡ Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/adityajha2118/portfolio.git

# 2. Navigate to project root
cd portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Build for production:
```bash
npm run build
```
